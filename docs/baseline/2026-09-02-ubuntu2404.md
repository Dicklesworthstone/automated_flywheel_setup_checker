## Findings (added 2026-09-02 22:10 UTC)

- 43 of 48 pass on `ubuntu:24.04` against ACFS `4567aad88f25`, versus 35 on `ubuntu:22.04` earlier the same day
  (the 22.04 run also predated the upstream checksum regeneration).
- `cass`, `ubs`, `srps`: `checksum_mismatch` — the pinned installers changed upstream after the checkout
  regenerated its checksums. `remediate checksums` verified the new cass (7 s) and ubs pins on 24.04; srps is new.
- `fsfs`: `dependency` — the fsfs v1.8.0 release binary needs `GLIBC_2.43`, which no Ubuntu LTS ships (24.04 has
  2.39). This is an upstream release-pipeline issue (build on an older glibc or link musl), not a checker or ACFS
  configuration problem.
- `mcp_agent_mail`: the installer fails closed without `minisign`, which ACFS installs in its "required apt
  packages" step before any tool installer. The prepared image lacked it; `docker/Dockerfile.base` now installs
  `minisign` and `libsqlite3-dev`, the ACFS drift test checks that step, and a re-check on the rebuilt image
  passes (`mcp_agent_mail` 29 s, `caam` 13 s; `fsfs` still fails as above).
